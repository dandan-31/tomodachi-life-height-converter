# Tomodachi Life Height Converter

A fan-made calculator that converts Tomodachi Life: Living the Dream Mii height slider values into estimated real-life heights.

Use the calculator here:

https://tomodachi-life-ltd-height-calculator--dandan31.replit.app/

## About

This tool helps players estimate how tall their Mii would be in real life based on the Tomodachi Life height slider. It supports feet/inches and centimeters, and lets users customize the height range if they want different slider values.
